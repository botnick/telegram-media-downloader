ความสามารถ

เก็บไฟล์จาก Telegram อัตโนมัติ ไม่ต้องคอยเฝ้า

ล็อกอินด้วยบัญชีของคุณ แล้วโหลดไฟล์จากช่องและกลุ่ม Telegram ได้ทั้งหมด รวมถึงแชตส่วนตัวที่คุณอยู่

โหลดอัตโนมัติ

เฝ้าช่อง กลุ่ม forum topic และแชตส่วนตัวแบบเรียลไทม์ ดึงข้อความย้อนหลังได้และทำต่อหลังรีสตาร์ท โหลดจากลิงก์ t.me, Stories, สื่อที่ตั้งเวลาลบตัวเอง และส่งต่ออัตโนมัติ

หน้าเว็บและแอปบนมือถือ

แกลเลอรี คิวโหลดพร้อมความเร็วและเวลาที่เหลือ ตัวดูแบบเต็มจอ และลิงก์แชร์ไฟล์ที่ตั้งวันหมดอายุได้ ติดตั้งเป็นแอปบนมือถือได้ มีภาษาไทย

ไม่โหลดไฟล์ซ้ำ

ข้ามไฟล์ที่มีอยู่แล้วก่อนโหลด ตรวจซ้ำด้วย SHA-256 และมีเครื่องมือสแกนหาไฟล์ซ้ำในคลังเพื่อลบทีเดียว

อัปเดตคลิกเดียว

กด Install update ในหน้าเว็บ หรือตั้งให้อัปเดตเองตามเวลา ระบบสำรองฐานข้อมูลให้ก่อนทุกครั้ง

ปลอดภัยตั้งแต่แรก

ไม่มีใครเข้าได้จนกว่าจะตั้งรหัสผ่าน มีบัญชีผู้ชมแบบอ่านอย่างเดียว ยกเลิก session ได้ และ session ของ Telegram ถูกเข้ารหัส

เชื่อมหลายเครื่อง

จับคู่หลายเครื่องเข้าด้วยกัน เปิดดูและเล่นไฟล์ของทุกเครื่องจากหน้าเดียว และล้างไฟล์ซ้ำข้ามเครื่อง

สำรองข้อมูล

สำรองไปที่ดิสก์ในเครื่อง, S3, SFTP, FTP/FTPS, Google Drive หรือ Dropbox เลือกเข้ารหัสได้ และกู้คืนแบบออฟไลน์ได้

AI เสริม

ภาพตัวอย่างตอนเลื่อนวิดีโอมีในตัว จดจำใบหน้าและคัดกรองภาพ 18+ ได้ผ่าน container เสริม tgdl-faces และ tgdl-nsfw

ไฟล์เดียวจบ

tgdl-server รันทั้งหน้าเว็บ บัญชี Telegram การโหลด และการสำรองข้อมูล ไม่ต้องลง Node.js หรืออะไรเพิ่ม มี Docker image สำหรับ amd64 และ arm64

เริ่มใช้งาน

ติดตั้งเสร็จในไม่กี่นาที

ต้องมี Docker พร้อม Compose และ apiId / apiHash จาก my.telegram.org (ขอได้ฟรี)

bash
mkdir telegram-media-downloader && cd telegram-media-downloader
mkdir -p data
curl -fsSLO https://raw.githubusercontent.com/botnick/telegram-media-downloader/main/docker-compose.yml
docker compose up -d
# ตั้งรหัสผ่านแรก จากไฟล์ที่มีรหัสผ่านบรรทัดเดียว:
docker compose exec -T -u node telegram-downloader \
  tgdl-server setup --password-stdin < password.txt

อัปเดต: กด Settings › Maintenance › Install update หรือใส่ WATCHTOWER_HTTP_API_PERIODIC_POLLS=true ใน .env ให้อัปเดตเองทุกวัน หรือรัน docker compose pull && docker compose up -d

ใช้ 2.x อยู่? อัปเป็น 3.x ได้เลย image พอร์ต โฟลเดอร์ข้อมูล และบัญชีเดิมใช้ต่อได้ รายละเอียดการอัปเกรด

ไม่มี Docker? ดาวน์โหลดไฟล์โปรแกรมสำหรับ Linux, Windows หรือ macOS แล้วรัน TGDL_DATA_DIR=./data ./tgdl-server ดูคู่มือติดตั้ง

  1. เข้าสู่ระบบเปิด http://localhost:3000 แล้วใส่รหัสผ่านที่ตั้งไว้
  2. ใส่ API ของ TelegramSettings › Telegram API
  3. เพิ่มบัญชีเบอร์โทร รหัสยืนยัน และรหัส 2FA ถ้ามี
  4. เริ่มเฝ้าแชตหรือวางลิงก์ t.me/ เพื่อโหลดทีละข้อความ
