Features

Archive Telegram without the babysitting

Sign in with your own account and download Telegram channel and group media, including private chats you belong to.

Auto-download

A self-restarting realtime monitor for channels, groups, forum topics and DMs, history backfill that resumes after restarts, t.me links, Stories, self-destructing media and auto-forward.

Web dashboard and PWA

Gallery, live queue with speed and ETA, a full-screen viewer and signed share links. Installable on a phone, English and Thai.

Dedup

Duplicates are skipped before downloading by Telegram media identity and confirmed by SHA-256. A library scan bulk-deletes the rest.

One-click updates

Press Install update in the dashboard, or let the stack update itself on a schedule. A verified database snapshot is saved first.

Secure by default

Nothing opens until a password is set. scrypt hashes, server-side session revocation, a read-only guest role and encrypted Telegram sessions.

Cluster mode

Pair several instances, sync their catalogs, open or play each other’s files from one dashboard and sweep duplicates across peers.

Backups

Mirror or snapshot to a local disk, S3-compatible storage, SFTP, FTP/FTPS, Google Drive or Dropbox, with encrypted archives and an offline restore command.

Optional AI

Video seekbar previews built in. Face recognition and NSFW review through the optional tgdl-faces and tgdl-nsfw containers.

One Go binary

tgdl-server runs the dashboard, Telegram accounts, downloads and backups. No Node.js, no runtime to install. Docker image for amd64 and arm64.

Quick start

Up in a few minutes

You need Docker with Compose and an apiId / apiHash from my.telegram.org.

bash
mkdir telegram-media-downloader && cd telegram-media-downloader
mkdir -p data
curl -fsSLO https://raw.githubusercontent.com/botnick/telegram-media-downloader/main/docker-compose.yml
docker compose up -d
# first password, from a private one-line file:
docker compose exec -T -u node telegram-downloader \
  tgdl-server setup --password-stdin < password.txt

Updating: use Settings › Maintenance › Install update, set WATCHTOWER_HTTP_API_PERIODIC_POLLS=true in .env for daily automatic updates, or run docker compose pull && docker compose up -d.

Coming from 2.x? 3.x upgrades in place: same image, port, data folder and logins. Upgrade notes.

No Docker? Download a release binary for Linux, Windows or macOS and run TGDL_DATA_DIR=./data ./tgdl-server. See the install guide.

  1. Sign inOpen http://localhost:3000 with the password you set.
  2. Add your API credentialsSettings › Telegram API.
  3. Add an accountPhone number, login code and optional 2FA.
  4. Start the monitorOr paste a t.me/ link to grab one message.
