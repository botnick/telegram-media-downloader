Features

Archive Telegram without the babysitting

Sign in with your own account and download Telegram channel and group media, including private chats you belong to.

Auto-download

A realtime monitor for channels, groups, forum topics and DMs, plus bulk backfill with date and count filters. Stories and self-destructing media too.

Web dashboard and PWA

Gallery, live queue with speed and ETA, a full-screen viewer, seekbar previews and share links. Installable on a phone, English and Thai.

Dedup

SHA-256 at download time and an on-demand library scan, with bulk delete for the duplicates it finds.

Face clustering

Optional insightface sidecar groups the people in your photos and videos. Run it locally or on a GPU machine.

NSFW review

A review screen with a whitelist and a hash blocklist, using a local classifier or a remote sidecar.

Cluster mode

Pair several instances into one federated library with live sync, failover and cluster-wide search.

Backups

Mirror to S3-compatible storage, SFTP, FTP, Google Drive, Dropbox or a local mount, with optional client-side encryption.

Go engine

tgdl-core, a small Go binary, does the hashing, integrity checks and folder walks, and serves every media byte, so playback stays smooth while the server is busy.

Quick start

Up in 60 seconds

You need Docker with Compose and an apiId / apiHash from my.telegram.org.

bash
git clone https://github.com/botnick/telegram-media-downloader.git
cd telegram-media-downloader
docker compose up -d

Updating: use Settings › Maintenance › Install update, or run docker compose pull && docker compose up -d.

  1. Open the dashboardhttp://localhost:3000, then set a password.
  2. Add your API credentialsSettings › Telegram API.
  3. Add an accountPhone number, login code and optional 2FA.
  4. Start the monitorOr paste a t.me/ link to grab one message.
